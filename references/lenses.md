# Thinking lenses

Use this reference only when a problem is broad, complex, or producing near-duplicate candidate questions. Pick a small set of lenses that create genuinely different hypotheses; do not mechanically apply every lens.

| Lens | Search for |
| --- | --- |
| First principles | What fundamentally determines the outcome? |
| Causal thinking | Which variables cause the outcome rather than correlate with it? |
| Theory of constraints | What is the dominant bottleneck now? |
| 80/20 | Which few factors explain most of the result? |
| Systems thinking | Where do interactions, feedback loops, or leverage points matter? |
| Inversion | What would reliably make the goal fail? |
| Expected value | Which uncertainty most changes the expected outcome? |
| Opportunity cost | What is forgone by choosing this path? |
| Marginal thinking | Where would the next unit of effort yield the largest return? |
| Second-order effects | What follows after the immediate result? |
| Risk | Which probability-times-impact combinations dominate? |
| Reversibility | Which decisions are difficult or expensive to undo? |
| Jobs To Be Done | What progress is the user actually trying to make? |
| Incentives | What behavior do the relevant incentives produce? |
| Funnel | At which stage does the largest loss occur? |
| Counterfactual | Would the result still occur if the suspected factor were removed? |

Prefer a question that identifies a decision-relevant unknown. A framework label is never the output.
