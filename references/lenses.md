# Thinking lenses

Use this reference for every nontrivial reframing. Its purpose is to prevent premature convergence on the first plausible interpretation while keeping the selected problem open to revision as evidence changes.

Select 3–6 lenses that create competing hypotheses, normally from at least three different families. Use each useful lens to generate one or more candidates. For consequential or genuinely complex work, the combined search should usually produce 5–15 materially different formulations. Stop only when additional candidates no longer reveal a decision-relevant target, not when the first reasonable explanation appears.

A useful candidate identifies:

- what currently needs to be resolved
- which observations are facts, which are inferences, and which are unknown
- what evidence would strengthen or weaken the formulation
- what answer, decision, intervention, experiment, or completed action would create useful progress now

## Goal and value

| Lens | What it tests | Internal probe |
| --- | --- | --- |
| First principles | What fundamentally determines the outcome once conventions and inherited assumptions are removed? | Which condition must be true for the desired result to exist at all? |
| Jobs To Be Done | What progress the person is actually trying to make in this situation | What change is the proposed solution being hired to create? |
| Opportunity cost | What valuable alternative, time, attention, or flexibility is displaced | What are we giving up by continuing down this path? |
| Value conflict | Whether several desired outcomes pull in incompatible directions | Which tradeoff belongs to the user rather than to the agent? |

## Causality and truth

| Lens | What it tests | Internal probe |
| --- | --- | --- |
| Evidence calibration | Whether confidence matches the quality of the observations | What is directly known, what is inferred, and what remains unknown? |
| Causal thinking | Which variables produce the outcome rather than merely correlate with it | What evidence would distinguish the suspected cause from a competing cause? |
| Competing explanations | Whether another hypothesis fits the same facts as well or better | What different cause would also explain what we see? |
| Counterfactual | Whether the outcome would still occur without the suspected factor | If this factor disappeared, would the problem remain? |
| Falsification | Whether the working formulation can be corrected rather than protected | What plausible finding would show that this is the wrong problem? |
| Inversion | What would reliably prevent or destroy success | What failure condition matters more than the proposed improvement? |

## Constraints and leverage

| Lens | What it tests | Internal probe |
| --- | --- | --- |
| Theory of constraints | Which current bottleneck limits the whole outcome | What single constraint makes improvement elsewhere mostly irrelevant now? |
| 80/20 | Which small number of causes explain most of the result | Which few inputs account for most of the current gap? |
| Systems thinking | Where interactions, feedback loops, delays, or leverage points dominate | What feedback loop keeps recreating the problem? |
| Funnel | At which stage the largest meaningful loss occurs | Where do suitable people, attempts, or value drop out most? |
| Marginal thinking | Where the next unit of effort produces the greatest incremental return | Where would one more unit of effort matter most now? |

## Decisions and consequences

| Lens | What it tests | Internal probe |
| --- | --- | --- |
| Expected value | Which option has the strongest probability-weighted outcome | Which choice remains worthwhile after likelihood and impact are considered together? |
| Risk | Which probability-times-impact combination dominates the downside | What plausible failure would be unacceptable even if unlikely? |
| Reversibility | Which choice is costly or difficult to undo | What must be learned before making the least reversible move? |
| Second-order effects | What follows after the immediate visible result | If this works initially, what new behavior or constraint appears next? |

## Learning and adaptation

| Lens | What it tests | Internal probe |
| --- | --- | --- |
| Value of information | Which unknown is worth resolving before acting | Which answer could actually reverse the next decision, and is it worth the cost of learning? |
| Discriminating experiment | Which small action can separate competing explanations | What affordable test would produce different results if the leading hypotheses differ? |
| Feedback speed | How quickly reality can correct the current judgment | Which action creates useful evidence soon enough to guide the next move? |
| Survivability | Whether failure leaves enough resources and flexibility to continue | Can we afford to be wrong and still make another attempt? |

## Behavior and incentives

| Lens | What it tests | Internal probe |
| --- | --- | --- |
| Incentives | What behavior the actual rewards, costs, status, or rules produce | What are people rewarded for doing, regardless of stated intent? |

## Selection discipline

Start with lenses that could disagree with one another. A strong default is:

1. one goal or value lens
2. one causal, evidence, or falsification lens
3. one constraint or system lens
4. one decision, risk, or learning lens
5. an incentives lens when other people or repeated behavior materially shape the outcome

For open or adaptive work, always test the decisive unknown, the value of learning more, and whether the next move is reversible or survivable. For bounded work, emphasize causal diagnosis, the current constraint, and observable acceptance conditions.

If all formulations support the user's initial theory, deliberately choose a lens that could falsify it. If every formulation is abstract, add a lens that locates a present constraint or executable intervention. If every formulation is tactical, add a lens that tests the intended outcome or causal model. If several values conflict, do not silently choose the tradeoff for the user.

Use the winning formulation as the current focus, act on it, and update it when the result provides new evidence. Keep the framework inventory and candidate tournament internal unless the user asks for an appropriate explanation.
